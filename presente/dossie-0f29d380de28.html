Seção 01 · Fundação

Base: o que instalar primeiro

Quase todas as skills criativas apoiam-se em cinco ferramentas de base no sistema operacional (mais o Playwright para exportar artes HTML em PNG de alta resolução). Instale tudo em disco interno rápido (SSD principal, como C:\ no Windows), nunca em HD externo USB.

Windows (PowerShell via winget)

  1. Abra o PowerShell e instale os cinco pacotes de base:
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.12 -e
winget install --id astral-sh.uv -e
winget install --id Gyan.FFmpeg -e
  1. Feche e reabra o terminal para atualizar o PATH.
  2. Instale o Playwright e o navegador Chromium para exportação de slides/carrosséis:
pip install playwright
python -m playwright install chromium

macOS (Terminal via brew)

  1. Com o Homebrew instalado, rode no Terminal:
brew install git node python@3.12 uv ffmpeg
  1. Reabra o terminal (ou recarregue seu ~/.zshrc).
  2. Instale o Playwright e o Chromium:
pip3 install playwright
python3 -m playwright install chromium
Ferramenta Para que serve no arsenal criativo Observação de versão Comando de conferência
Node.js LTS Executa CLIs de vídeo em HTML (HyperFrames, OpenFilm, Huashu Motion), GSAP, Remotion e servidores MCP via npx. HyperFrames exige Node.js 22+. Verifique se o LTS instalado é 22 ou superior. node -v
Python 3.12 Roda scripts das skills de corte/áudio (ffmpeg-skill), exportação de slides e geração de ativos. 3.12 é o ponto ideal de compatibilidade geral (nota: manimgx isolado pede 3.13+ via uv). python --version / python3 --version

Seção 02 · Agentes & Diretórios

Como instalar skills no Claude Code e no Google Antigravity

Uma skill nada mais é do que uma pasta contendo um arquivo SKILL.md (com instruções especializadas, regras de direção de arte e referências) e, às vezes, pastas auxiliares como scripts/, references/ e templates/. Tanto o Claude Code quanto o Antigravity leem exatamente o mesmo formato.

Importante sobre o Google AI Ultra e o Gemini CLI: o antigo Gemini CLI parou de aceitar contas pessoais em 18/06/2026. Para usar sua conta pessoal com o plano Google AI Ultra na linha de comando e no desktop, use o Google Antigravity (aplicativo desktop + CLI agy).

1. No Claude Code

  • Onde ficam as skills globais: ~/.claude/skills/ (no Windows: C:\Users\<SeuUsuario>\.claude\skills\).
  • Onde ficam por projeto (opcional): .claude/skills/ na raiz do projeto.
  • Plugins de marketplace: instalados dentro de uma sessão interativa do Claude Code com os comandos /plugin marketplace add dono/repo e depois /plugin install.

Passo a passo com git clone (macOS/Linux ou Git Bash/PowerShell):

# 1. Crie a pasta global de skills se ainda não existir
mkdir -p ~/.claude/skills

# 2. Entre na pasta e clone uma skill direta
cd ~/.claude/skills
git clone https://github.com/blader/humanizer.git

2. No Google Antigravity (app + CLI agy)

  • Onde ficam as skills globais: ~/.gemini/antigravity-cli/skills/ (no Windows: C:\Users\<SeuUsuario>\.gemini\antigravity-cli\skills\).
  • Onde ficam por projeto: .agents/skills/ na raiz do projeto.
  • Regra de ouro #1 (limite de catálogo): o catálogo automático do Antigravity comporta cerca de ~248 skills. Se você jogar centenas de pastas lá dentro, as excedentes ficam de fora da listagem automática.
  • Regra de ouro #2 (sem atalhos): o Antigravity não segue atalhos de pasta (symlinks ou junctions do Windows). Copie as pastas reais!

Truque para usar todas as skills sem estourar o limite de ~248: mantenha as pastas clonadas em ~/.claude/skills/ (ou copie só as favoritas para ~/.gemini/antigravity-cli/skills/) e liste os caminhos completos dos SKILL.md no seu arquivo global ~/.gemini/GEMINI.md dizendo ao agente para ler o SKILL.md correspondente antes de executar a tarefa.

Atenção à estrutura dos repositórios (skill única vs. coleção de skills)

Existem dois tipos de repositório no GitHub:

  1. Repositório de skill única (ex.: humanizer, huashu-motion, huashu-design, design-dna): o SKILL.md já está na raiz do repositório. Basta dar git clone dentro da pasta de skills.
  2. Repositório-coleção (ex.: hyperframes, gsap-skills, marketingskills, motion-design-skill, design-motion-principles, brand-skills): o repositório guarda várias subpastas dentro de skills/<nome>/SKILL.md. Nesse caso você pode usar o instalador universal npx skills add <dono/repo> ou clonar o repositório e copiar o conteúdo de skills/* para a pasta de skills do agente.

Copiando uma skill para o Antigravity (PowerShell no Windows / Terminal no Mac):

# Windows (PowerShell) — copia pastas reais (sem atalho)
New-Item -ItemType Directory -Force "$HOME\.gemini\antigravity-cli\skills"
Copy-Item -Recurse -Force "$HOME\.claude\skills\humanizer" "$HOME\.gemini\antigravity-cli\skills\"
Copy-Item -Recurse -Force "$HOME\.claude\skills\gsap-skills\skills\*" "$HOME\.gemini\antigravity-cli\skills\"

hyperframes
Repositório público 19 subskills inclusas
O que é
Framework aberto que transforma composições em HTML, CSS e animações controladas no tempo em vídeos MP4 determinísticos, guiado pela skill roteadora hyperframes.
Quando usar
1) Criar vídeos de lançamento de produto a partir da URL de um site (product-launch-video), vídeos explicativos sem rosto (faceless-explainer), vinhetas curtas (motion-graphics) ou clipes sincronizados na batida da música (music-to-video).
2) Colocar legendas animadas (embedded-captions) ou cartões gráficos (talking-head-recut) sobre um vídeo de alguém falando, explicar um Pull Request do GitHub (pr-to-video), criar decks interativos (slideshow) ou migrar projetos do Remotion (remotion-to-hyperframes).
Subskills de suporte em skills/: general-video, figma, media-use, hyperframes-cli, hyperframes-core, hyperframes-animation, hyperframes-creative, hyperframes-keyframes e hyperframes-registry.
Como instalar
# Opção 1: instalador de skills (instala o conjunto principal sob demanda)
npx skills add heygen-com/hyperframes --full-depth

# Opção 2: git clone em ~/.claude/skills/
cd ~/.claude/skills && git clone https://github.com/heygen-com/hyperframes.git
O que precisa
Node.js 22+ e FFmpeg instalados localmente. Renderização local 100% gratuita (sem chave de API obrigatória; nuvem/modelos externos são opcionais).
Pedido de exemplo
"Usando /hyperframes, crie um vídeo de 20 segundos em 9:16 apresentando meu aplicativo de controle financeiro pessoal, com abertura tipográfica forte, demonstração de tela animada e prévia no navegador antes de renderizar o MP4."

Seção 06 · Solução Rápida

Problemas comuns e como resolver

Sintoma / Erro Causa raiz Como resolver na hora
Gemini CLI recusa login na conta pessoal ou não reconhece o plano Ultra O Gemini CLI encerrou o suporte a contas pessoais em 18/06/2026. Instale e use o Google Antigravity (aplicativo desktop e CLI agy), que é onde o plano Google AI Ultra funciona para contas pessoais.
Skill instalada não aparece no Antigravity Ou você criou um atalho de pasta (symlink/junction), ou ultrapassou o teto de ~248 skills no catálogo automático. 1) Substitua qualquer atalho por uma cópia real da pasta em ~/.gemini/antigravity-cli/skills/.
2) Deixe no catálogo automático só as mais usadas e liste os caminhos exatos dos demais SKILL.md no seu ~/.gemini/GEMINI.md para o agente ler com a ferramenta de leitura quando precisar.
Clonei um repositório em skills/, mas o agente não acha as subskills Repositórios-coleção (como marketingskills, gsap-skills e hyperframes) guardam cada skill um nível abaixo, em repo/skills/<nome>/SKILL.md. Rode npx skills add <dono/repo> (que já posiciona cada subpasta no lugar certo) ou copie o conteúdo interno de repo/skills/* para a raiz da pasta de skills do agente.
HyperFrames falha ao iniciar ou ao gerar MP4 Versão do Node abaixo da 22 ou ffmpeg fora do PATH do sistema. Rode node -v (atualize se for menor que v22) e ffmpeg -version. No Windows, após instalar via winget, é obrigatório fechar todas as janelas de terminal e abrir uma nova.
Acentos em português viram ? ou em scripts no Windows O PowerShell clássico interpreta argumentos literais na linha de comando em ANSI em vez de UTF-8. Oriente o agente no seu CLAUDE.md / GEMINI.md: "Nunca passe texto em português com acento direto em argumentos do PowerShell; grave sempre o arquivo ou JSON em UTF-8 pela ferramenta de escrita ou Python."
Playwright falha ao exportar carrossel (Executable doesn't exist) ou fonte sai genérica O pacote Python foi instalado, mas o binário do Chromium não foi baixado — ou o print saiu antes de baixar a Google Font. Rode python -m playwright install chromium. Nos scripts de exportação, aguarde wait_until="networkidle" + 2 a 3 segundos extras antes do screenshot.
ComfyUI acusa falta de memória (CUDA out of memory) em GPU de 8 GB Checkpoint pesado demais em precisão máxima (FP16/FP32) ou resolução inicial muito alta de uma vez só. Use versões FP8 ou GGUF dos modelos de imagem, gere primeiro na resolução base (ex.: 1024×1024 ou 1280×720) antes de passar por um nó de upscale separado e, se necessário, adicione --lowvram no arquivo .bat de abertura.
No Mac, digitar od roda um comando estranho em vez do Open Design O macOS já vem com um utilitário nativo /usr/bin/od (octal dump) que ganha prioridade no PATH. Abra o app desktop do Open Design → Settings → MCP server e copie o trecho de configuração com caminho absoluto em vez de chamar od solto no terminal.
ComfyUI ou projetos de vídeo travando e demorando minutos para abrir Arquivos grandes de modelos ou node_modules instalados em HD externo USB mecânico. Mantenha ferramentas locais, ambientes Python/Node e modelos sempre no SSD interno principal (C:\ no Windows). Use disco externo só para arquivar vídeos já finalizados.
